# Striatal Tissue iron, Cognitive Control, and Attention Problems in Children

Code and analysis scripts accompanying a study examining associations among striatal tissue iron, cognitive control, and attention problems during development.

## Study summary
Cognitive control was assessed using the Flanker task. Tissue iron was estimated using MRI-derived measures from striatal regions of interest. Primary analyses tested whether individual differences in tissue iron moderated age-related variation in cognitive control and attention-related outcomes.
